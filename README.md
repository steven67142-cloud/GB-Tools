# XQ 推薦碼 `＠GB`

> [!IMPORTANT]
> ## 使用腳本前，請先綁定推薦碼 `＠GB`
>
> 1. 真雲鳳凰：免費腳本不須綁定，可直接下載使用。
> 2. 其他指標：需綁定XQ推薦碼＠GB才能執行腳本。
## 腳本下載

請進入 [XQ-Scripts](XQ-Scripts/) 下載目前發布的選股腳本。

## 探吉島遊戲

宣傳截圖見 [XQ-Scripts README](XQ-Scripts/README.md#探吉島美食物語遊戲宣傳)。  
須綁定推薦碼 **`＠GB`** → 執行[外資買進](XQ-Scripts/外資買進_v1.0/) → 於**腳本描述**取得入社／遊戲連結（網址不公開於本站）。
