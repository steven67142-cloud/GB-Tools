# 台指期看盤介面

> [!IMPORTANT]
> 2. 其他指標：需綁定XQ推薦碼＠GB才能執行腳本。

台指期分 K「看盤介面」三件套：主圖戰情（全天版）＋大戶攻擊力＋ADX。建議同框使用。

![台指期看盤介面示意](./txo_battle_overview_demo_v2.png)

## 內含檔案

| 檔案 | 用途 |
|------|------|
| `自訂_期貨戰情全天版_v1.0_推薦碼GB.xsb` | 主圖戰情（全天版：日盤／夜盤通用；趨勢／主力／掛單／量能 → 決策） |
| `盤中大戶即時攻擊力_v1.0_推薦碼GB.xsb` | 副圖：內外盤淨攻擊力 |
| `自訂_ADX_v1.0_推薦碼GB.xsb` | 副圖：強趨勢 vs 區間震盪 |
| `txo_battle_overview_demo_v2.png` | 同框示意圖 |

## 安裝方式

1. 下載上述三個 `.xsb`
2. XQ → XScript 編輯器 → **匯入**
3. 開台指期分 K：主圖掛「期貨戰情全天版」，副圖掛「大戶攻擊力」與「ADX」

## 使用權限

- 已綁定推薦碼 `＠GB` 可執行
- 未綁定無法執行
- 作者帳號可執行
