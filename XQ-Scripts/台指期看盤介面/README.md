# 台指期看盤介面

> [!IMPORTANT]
> 2. 其他指標：需綁定XQ推薦碼＠GB才能執行腳本。

台指期分 K「看盤介面」三件套：主圖戰情＋大戶攻擊力＋ADX。建議在15分K週期使用。

![台指期看盤介面示意](./txo_battle_overview_demo_v2.png)

## 內含檔案

| 檔案 | 用途 |
|------|------|
| `自訂_期貨戰情全天版_v1.0_推薦碼GB.xsb` | 主圖戰情（全天版：日盤／夜盤通用；趨勢／主力／掛單／量能 → 決策） |
| `盤中大戶即時攻擊力_v1.0_推薦碼GB.xsb` | 副圖：內外盤淨攻擊力 |
| `自訂_ADX_v1.0_推薦碼GB.xsb` | 副圖：強趨勢 vs 區間震盪 |
| `txo_battle_overview_demo_v2.png` | 同框示意圖 |

## 安裝方式

1. 下載上述三個 `.xsb`
2. XQ → XScript 編輯器 → **匯入**
3. 開台指期分 K：主圖掛「期貨戰情全天版」，副圖掛「大戶攻擊力」與「ADX」
4. **ADX 顯示柱圖步驟**：右鍵設定 → 副圖設定 → `自訂_ADX_v1.0` → 繪圖樣式 → Plot1 型式 → **柱圖** → 樣式 → **正負**

## 使用權限

- 已綁定推薦碼 `＠GB` 可執行
- 未綁定無法執行
- 作者帳號可執行

## ❓ 常見問題與除錯 (Troubleshooting)

### Q: 主圖上方沒有顯示「戰情總覽」文字？

如果將指標套用至主圖後，左上角完全沒有出現戰情總覽文字，通常是 **XQ 的主圖指標字體設定過大** 導致版面無法完整繪製。

**解決步驟：**

1. 在 K 線主圖任意空白處點擊 **右鍵** → 選擇 **`頁面設定`**（或按下快速鍵 `Alt + Enter`）。
2. 切換至 **`字型`** 分頁。
3. 找到 **`指標名稱/數值字型`**，將字體大小 **連續縮小 2 級**（例如：從 14Pt 調整為 12Pt，或 12Pt 調整為 10Pt）。
4. 點擊 **確定** 儲存，主圖標題文字即可順利恢復顯示。
