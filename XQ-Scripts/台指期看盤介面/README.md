# 台指期看盤介面

> [!IMPORTANT]
> 2. 其他指標：需綁定XQ推薦碼＠GB才能執行腳本。

## 安裝方式

1. 下載 **V1.2 主圖疊圖**、**大戶攻擊力 v1.1**、**ADX**（共三個）
2. XQ → XScript 編輯器 → 戰情／ADX **匯入** `.xsb`；大戶 v1.1 可開 `.txt` 貼上後編譯／另存
3. 開台指期分 K：**主圖**掛「期貨戰情表」（疊圖），**副圖**掛「大戶攻擊力」與「ADX」
4. **ADX 顯示柱圖步驟**：右鍵設定 → 副圖設定 → `自訂_ADX_v1.0` → 繪圖樣式 → Plot1 型式 → **柱圖** → 樣式 → **正負**

## ❓ 常見問題與除錯 (Troubleshooting)

### Q: 請問指標準嗎？

世界上並不存在準的指標，市場的未來走勢有著不可預測性。用在 15 分 K 的用意是可以看穿全市場的動態，至少不要跟市場做相反的方向。

### Q: 指標是用 15 分 K，其他週期可以嗎？

看你做的週期決定。短進短出可以用 5K 或 1K，但相對的容易被洗。如用 5K 就是 8:50 的收盤價出報告，15K 就是 9:00 收盤價出報告，1K 就是即時，依此類推。

### Q: 主圖上方沒有顯示「戰情總覽」文字？

**請優先改用 V1.2 精簡大字版**（`期貨戰情表V1.2精簡大字版.xsb`），版面已針對主圖字體空間優化。

若仍無法顯示，通常是 **XQ 的主圖指標字體設定過大** 導致版面無法完整繪製。

**解決步驟：**

1. 在 K 線主圖任意空白處點擊 **右鍵** → 選擇 **`頁面設定`**（或按下快速鍵 `Alt + Enter`）。
2. 切換至 **`字型`** 分頁。
3. 找到 **`指標名稱/數值字型`**，將字體大小 **連續縮小 2 級**（例如：從 14Pt 調整為 12Pt，或 12Pt 調整為 10Pt）。
4. 點擊 **確定** 儲存，主圖標題文字即可順利恢復顯示。
