# 盤中大戶即時攻擊力 v1.0

> [!IMPORTANT]
> 本腳本僅限已綁定 XQ 推薦碼 **`@GB`** 的使用者執行。

## 腳本介紹

適用於**台指期當日分 K**，計算即時內外盤差（外盤量 − 內盤量），以「大戶淨攻擊力」呈現主力偏多／偏空／觀望，並在圖表標籤顯示操作提示。

實際計算細節與門檻邏輯不公開。

## 功能特色

- 讀取當日累積外盤量／內盤量
- 繪製淨攻擊力與零軸
- 依門檻動態變色與標籤（偏多攻堅／偏空打壓／觀望）

## 安裝方式

1. 下載 `.xsb` 檔案
2. 開啟 XQ 全球贏家 → XScript 編輯器 → **匯入**
3. 將指標加入**台指期分 K 圖**副圖
