# 探吉島入社導引 v1.0

> 綁定推薦碼 `@GB` 後執行本腳本，自動顯示社群連結（免人工私訊網址）。

## 使用方式（玩家）

1. 先綁定 XQ 推薦碼 **`@GB`**
2. 下載本資料夾的 `.xsb`（檔名含「推薦碼GB」）
3. 在 XQ 匯入並執行
4. 畫面上會出現社群連結（與必要說明）
5. 進社群後再申請探吉島遊戲登入；遊戲憑證仍由管理員派發

## 維護方式（管理員／在 XQ 編輯器製作）

本機無法直接產生加密 `.xsb`，請在 **XQ 腳本編輯器**完成後匯出：

1. 新增腳本，名稱建議：`探吉島入社導引_v1.0`
2. 腳本內容：執行時輸出／提示 [`腳本文案.txt`](./腳本文案.txt) 全文（把 `【填入】` 換成真實網址）
3. 開啟 **推薦碼保護**，設為 `@GB`
4. 匯出為：`探吉島入社導引_v1.0_推薦碼GB.xsb`
5. 放到本資料夾並更新 GitHub（或交給管理員上傳）

## 檔案

| 檔案 | 說明 |
|------|------|
| `腳本文案.txt` | 貼進 XQ 腳本的顯示文字 |
| `探吉島入社導引_v1.0_推薦碼GB.xsb` | （待匯出上傳）受保護腳本本體 |

## 注意

- 未綁 `@GB` 者無法執行受保護腳本
- 本腳本只自動給「社群／說明網址」，不自動開遊戲帳號
