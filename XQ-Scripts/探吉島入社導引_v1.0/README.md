# 探吉島入社導引（掛在既有選股腳本）

> 不另做「假選股」。把遊戲網址加進**已能編譯、已有 `@GB` 保護**的選股腳本即可。

## 玩家怎麼拿到網址

1. 綁定 XQ 推薦碼 **`@GB`**
2. 下載並執行任一 GB 受保護選股（見下方建議腳本）
3. 看腳本**描述**或執行時**訊息**中的探吉島遊戲網址
4. 開啟網址建立／登入角色

## 管理員：在 XQ 怎麼改（建議先改一支）

建議先改：**外資買進 v1.0**（使用多、本來就有推薦碼保護）

1. XQ 開啟該選股原始腳本（可編譯的那份，不是純文字）
2. **描述**欄貼上或追加 [`描述_附加文案.txt`](./描述_附加文案.txt)
3. （可選）腳本開頭加 `Message(...)`：見 [`Message_附加程式碼.txt`](./Message_附加程式碼.txt)  
   - 若你這版 XQ 沒有 `Message`，只改「描述」即可
4. 編譯成功
5. 匯出時維持 **推薦碼保護 `@GB`／GB**
6. 用新的 `.xsb` 覆蓋 GitHub 對應資料夾（或交給管理員上傳）

其他腳本若要同步，同一組文案再貼一次即可。

## 注意

- 不要新建「只有中文說明、無法編譯」的選股
- 匯出時的「密碼保護」≠ 推薦碼；推薦碼請用原本的保護設定
