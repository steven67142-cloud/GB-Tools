## 使用方式（玩家）

1. 先綁定 XQ 推薦碼 **`@GB`**
2. 下載本資料夾的 `.xsb`（檔名含「推薦碼GB」）
3. 在 XQ 匯入並執行
4. 畫面上會出現探吉島遊戲網址
5. 開啟網址建立／登入角色

## 維護方式（管理員／在 XQ 編輯器製作）

本機無法直接產生加密 `.xsb`，請在 **XQ 腳本編輯器**完成後匯出：

1. 新增腳本，名稱建議：`探吉島入社導引_v1.0`
2. 腳本內容：執行時輸出／提示 [`腳本文案.txt`](./腳本文案.txt) 全文
3. 開啟 **推薦碼保護**，設為 `@GB`
4. 匯出為：`探吉島入社導引_v1.0_推薦碼GB.xsb`
5. 放到本資料夾並更新 GitHub
