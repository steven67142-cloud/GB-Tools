# 自訂_ADX v1.0

> [!IMPORTANT]
> 本腳本僅限已綁定 XQ 推薦碼 **`@GB`** 的使用者執行。

## 腳本介紹

以 ADX 判斷當前偏**強趨勢盤**或**區間震盪**，並在圖表標籤提示「順勢操作」或「切勿追高」。

實際計算細節與門檻邏輯不公開。

## 功能特色

- 計算 ADX 力道線
- 可調 ADX 期數與趨勢門檻（預設 20）
- 超過門檻標示強趨勢；低於門檻標示區間震盪

## 腳本下載

下載本資料夾內：

`自訂_ADX_v1.0_推薦碼GB.xsb`

## 安裝方式

1. 下載 `.xsb` 檔案
2. 開啟 XQ 全球贏家 → XScript 編輯器 → **匯入**
3. 將指標加入圖表副圖

## 使用權限

- 已綁定推薦碼 `@GB` 的帳號可以執行
- 未綁定推薦碼 `@GB` 的帳號無法執行
- 作者帳號可執行
